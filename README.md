Forecasts GTA VI's launch-day Twitch concurrent viewers hour by hour (hours 2–24, five quantiles each), from the case file alone: a comparable-launch ratio ensemble — each past big launch's launch-day curve normalized by its own hour-1 print, combined by a two-variable regression on log hour-1 magnitude and log pre-launch ratio, with an envelope guard keeping the forecast inside the shapes the comparables actually showed. Lab practice loss 0.1618 vs the house baseline 0.387.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
